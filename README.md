# 保研信息爬虫

爬取[保研网](http://www.baoyanwang.com.cn)上的推免招生信息，并导出为 Excel 文件。

## 功能

- 自动爬取所有页面的保研（推免）招生公告
- 提取关键字段：标题、学校、学院、专业、省份、学校层次、报名时间、活动时间、官方链接等
- 自动计算总页数，遍历爬取
- 可配置爬取间隔，避免请求过于频繁
- 数据保存为 `.xlsx` 格式，方便用 Excel 或 Pandas 进一步分析

## 输出字段

| 字段 | 说明 |
|------|------|
| id | 文章 ID |
| 标题 | 公告标题 |
| 发布时间 | 公告发布时间 |
| 学校 | 发布院校（从标题自动提取） |
| 学院 | 学院名称 |
| 专业 | 专业名称 |
| 省份 | 学校所在省份 |
| 学校层次 | 985/211/双一流 等 |
| 标签 | 内容标签 |
| 报名开始/结束时间 | 报名起止时间 |
| 活动开始/结束时间 | 活动起止时间 |
| 官方链接 / 报名链接 | 相关 URL |
| 内容摘要 | 正文摘要 |
| 申请人数 / 浏览人数 | 热度数据 |

## 使用方法

```bash
# 安装依赖
pip install requests pandas openpyxl

# 运行爬虫
python spider.py
```

数据默认保存为 `保研信息全量数据_YYYYMMDD.xlsx`。

## 依赖

- Python 3.6+
- requests
- pandas
- openpyxl
